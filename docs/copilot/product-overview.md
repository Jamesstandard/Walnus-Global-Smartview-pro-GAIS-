# SmartView-ai Product Overview

**Application:** SmartView Pro™  
**Copilot:** SmartView-ai  
**Organization:** Walnus Global Ventures  

## Purpose & Vision
SmartView-ai is an intelligent, application-integrated Copilot designed to operate as a permission-aware control plane for SmartView Pro™. It assists field surveyors, engineers, and project managers by explaining features, inspecting live application state, executing authorized tools, and providing real-time technical knowledge for construction surveying, surface profiling, and Walnus SmartCoat™ material estimation.

## Core Capabilities
- **Conversational Intelligence:** Local SLM integration with Vector RAG knowledge retrieval across 30+ construction and chemistry domains.
- **Application Control Plane:** Direct navigation, settings management, and tool orchestration.
- **Measurement Integrity:** Strict tracking of measurement provenance (`MEASURED`, `INFERRED`, `ESTIMATED`, `USER_CONFIRMED`, `AI_SUGGESTED`).
- **Device-Aware Adaptation:** Dynamic hardware capability detection with graceful degradation for varied mobile hardware.
