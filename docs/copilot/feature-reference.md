# SmartView-ai Feature Reference

Detailed functional specification for active SmartView Pro™ features:

- **ADAS Telemetry HUD:** Real-time pitch, roll, GPS coordinates, elevation, and structural integrity meters.
- **Surface Profiler:** Surface roughness metrics, estimated porosity, and substrate adherence scores.
- **SmartCoat Estimator:** Automated material calculation for paint, primer, screed, and plaster with color selection.
- **Offline-First Persistence:** Dexie v3 IndexedDB storage ensuring full field usability without internet connectivity.
- **Vector RAG Engine:** Local embedding search across chemical formulations, application standards, and safety guidelines.
