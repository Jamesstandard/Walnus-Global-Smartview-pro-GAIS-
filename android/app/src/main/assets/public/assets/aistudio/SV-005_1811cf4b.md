# SV-005 — Camera Intelligence & HUD Enhancement

**Milestone:** SV-005  
**Priority:** Critical  
**Category:** Camera / HUD / Visual Intelligence

## 1. Project Objective

Transform the existing SmartView Pro camera into a reliable, intelligent construction-survey camera.

Improve camera performance, visual clarity, orientation awareness, HUD overlays, screen pointers, and measurement-reference capabilities.

This milestone must preserve the existing camera implementation while improving its capabilities.

**Do not rebuild the camera from scratch. Do not remove working functionality.**

## 2. Required Functionality

### 2.1 Camera Engine

- Maintain the existing camera implementation and its established architecture.
- Improve camera initialization and lifecycle management.
- Optimize focus, exposure, and image clarity.
- Improve image capture resolution where hardware permits.
- Prevent unnecessary camera flickering.
- Maintain camera stability during screen rotation and application backgrounding.
- Preserve captured images and associated survey information.
- Provide appropriate camera recovery after permission denial or interruption.

### 2.2 Advanced HUD System

Implement a modular heads-up display.

Required features:

- Live camera overlays.
- Directional indicators.
- Horizontal and vertical reference lines.
- Dynamic screen pointers.
- Alignment guides.
- Compass and orientation indicators.
- Survey reference markers.
- Visual distance-reference indicators where supported.

HUD elements must remain responsive to camera movement and device orientation.

### 2.3 Elastic Screen Pointers

Implement elastic pointer behaviour.

Pointers and reference lines should:

- Respond smoothly to movement.
- Maintain visual attachment to their reference positions.
- Adjust dynamically to changes in camera orientation.
- Avoid unnecessary jitter.
- Maintain consistent positioning during camera movement.
- Support different screen sizes and aspect ratios.

### 2.4 4D ADAS-Inspired Camera Interface

Introduce relevant visual and interaction principles of advanced driver-assistance displays.

This is a construction-survey adaptation, not an automotive ADAS implementation.

Include:

- Spatial-awareness indicators.
- Directional guidance.
- Dynamic visual reference lines.
- Object-relative screen markers where technically supported.
- Camera alignment feedback.
- Real-time visual guidance.

Do not claim object detection or spatial accuracy unless the relevant functionality has been implemented and tested.

### 2.5 Device Compatibility

Develop for high-capability devices first, with adaptive fallback.

The system must:

- Detect available camera capabilities.
- Detect relevant device sensors.
- Adapt rendering quality.
- Support devices without advanced spatial capabilities.
- Avoid crashes when advanced sensors are unavailable.
- Maintain a usable camera experience on entry-level devices.

The Tecno Pop 7 must remain an important low-spec compatibility consideration.

## 3. Accuracy and Reliability

All measurements and references must have identifiable provenance.

Use the established measurement classifications:

- `MEASURED`
- `INFERRED`
- `ESTIMATED`
- `USER_CONFIRMED`
- `AI_SUGGESTED`

Never present an estimate as a physical measurement.

Where device limitations prevent reliable measurements, communicate that limitation clearly.

## 4. Architecture Requirements

Implement the HUD as independent, replaceable UI modules.

Separate:

1. Camera engine.
2. Camera preview.
3. HUD rendering.
4. Sensor integration.
5. Pointer and alignment engine.
6. Measurement-reference system.
7. Device capability detection.

Do not tightly couple the camera engine to the UI.

The UI must remain independently changeable without requiring a camera-engine rewrite.

## 5. Explicit Exclusions

The following are **not** part of this milestone:

- Full 3D Studio implementation.
- Image-to-3D reconstruction.
- Video-to-3D reconstruction.
- Complete surface-classification engine.
- AI-generated building reconstruction.

These features must not be introduced at the expense of camera stability.
